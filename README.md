# Загрязнение мирового океана микропластиком

Интерактивная визуализация проб морского микропластика и интенсивности загрязнения Мирового океана.

**Источник:** [NOAA NCEI Global Marine Microplastics Database](https://www.ncei.noaa.gov/)  
Nyadjro et al. (2023). *Scientific Data*. [doi:10.1038/s41597-023-02632-y](https://doi.org/10.1038/s41597-023-02632-y)

## Как открыть

Откройте `ocean-microplastics-map.html` в браузере. Карта в формате 4:3 и подстраивается под размер окна.

Для тайлов карты нужен доступ в интернет.

## Как пользоваться

| Элемент | Что делает |
| --- | --- |
| **Marine water samples** | Точки-пробы на карте. На синей линии графика (нарастающий итог измерений) появляются метки по годам. |
| **Pollution** | Точки окрашиваются по классу загрязнения. Метки по годам — на красной линии (нарастающий итог загрязнения). |

Точки пульсируют по мере смены года. Диапазон графика — 2008–2023. Линии дорисовываются вместе с годом; кружки остаются у уже прошедших лет.

### График

- **Красная линия — Cumulative pollution** — нарастающий итог загрязнения, шт/м³  
- **Синяя линия — Cumulative measurements** — нарастающий итог измерений (не число проб за один год)

## Классы загрязнения

| Class | Значение |
| --- | --- |
| Very Low | Очень низкая |
| Low | Низкая |
| Medium | Средняя |
| High | Высокая |
| Very High | Очень высокая |

## Данные

Наблюдения взяты из NOAA NCEI Global Marine Microplastics Database (NCEI Accession 0306475). В проекте показана выборка за 2008–2023. Источником записи остаётся исходный набор данных.
